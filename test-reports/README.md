# Test Reports

This directory contains example test reports and statistics generated by TiaCC during testing and analysis.

## 📋 Purpose

This directory serves as:

1. **Example Output**: Demonstrates what TiaCC generates during analysis
2. **CI Artifacts**: Can be used to store test reports in CI/CD pipelines
3. **Documentation Reference**: Shows the format and content of TiaCC reports

## 📁 Contents

### `cpp-project-stats.txt`

Example statistics from analyzing the C++ test project (`tests/e2e/cpp-project`).

**Shows:**
- Number of tests analyzed
- Coverage mapping statistics
- Source file to test file relationships
- Impact analysis results

## 🚀 Using in CI/CD

### GitHub Actions

```yaml
- name: Generate TiaCC report
  run: |
    tia-mapper --coverage ./coverage --output ./test-reports/mapping-stats.txt
    tia-recommend --database ./impact_map.db > ./test-reports/affected-tests.txt

- name: Upload test reports
  uses: actions/upload-artifact@v4
  with:
    name: tiacc-reports
    path: test-reports/
```

### GitLab CI

```yaml
tiacc-analyze:
  script:
    - tia-mapper --coverage ./coverage --stats ./test-reports/stats.txt
  artifacts:
    paths:
      - test-reports/
    expire_in: 30 days
```

### Azure Pipelines

```yaml
- task: PublishBuildArtifacts@1
  inputs:
    pathToPublish: 'test-reports'
    artifactName: 'TiaCC Reports'
```

## 📊 Report Types

TiaCC can generate various types of reports:

### 1. Mapping Statistics
- Total number of tests mapped
- Number of source files covered
- Average tests per source file
- Uncovered source files

### 2. Recommendation Report
- List of affected tests for current changes
- Changed files detected
- Coverage percentage of changes
- Test reduction ratio

### 3. Impact Analysis
- Test-to-code dependency graph
- High-impact source files (touched by many tests)
- Low-coverage areas
- Suggested improvements

## 🔧 Generating Reports

### Using CLI

```bash
# Generate mapping statistics
tia-mapper --coverage ./coverage --stats ./test-reports/mapping.txt

# Generate recommendation with details
tia-recommend --database ./impact_map.db --verbose > ./test-reports/recommendations.txt

# Export database statistics
tia-runner --export-stats ./test-reports/database-stats.json
```

### Using API

```typescript
import { TiaCC } from '@tiacc/tools';

const tia = new TiaCC({
  database: './impact_map.db'
});

// Generate statistics report
const stats = await tia.getStatistics();
await fs.writeFile('./test-reports/stats.json', JSON.stringify(stats, null, 2));

// Generate affected tests report
const affected = await tia.recommendTests({
  baseCommit: 'HEAD~1',
  currentCommit: 'HEAD'
});
await fs.writeFile('./test-reports/affected.txt', affected.join('\n'));
```

## 📈 Report Formats

### Text Format
```
=== TiaCC Mapping Statistics ===
Total Tests: 42
Total Source Files: 138
Mapped Relationships: 312
Average Tests/File: 2.3
Coverage: 85.5%
```

### JSON Format
```json
{
  "totalTests": 42,
  "totalSourceFiles": 138,
  "mappedRelationships": 312,
  "averageTestsPerFile": 2.3,
  "coveragePercentage": 85.5,
  "unmappedFiles": ["src/utils/legacy.js"]
}
```

## 🗑️ Cleanup

This directory may contain generated reports during development. To clean up:

```bash
# Keep example files, remove generated reports
find test-reports -type f ! -name '*-example.txt' ! -name 'README.md' -delete

# Or remove everything except README
find test-reports -type f ! -name 'README.md' -delete
```
